# Neural Atlas companion

See `neural-atlas/README.md` in the checkout. Atlas reads configured vault Markdown
and Graphify output, provides current-mode Brain search, and optionally runs bounded
Laya CPU classification. Suggestions live in a derived database and never change
canonical notes or hide ordinary search results.

Inspect source-hashed review packets and current full notes before saving distilled
results through Brain tools. Edits invalidate suggestions. Model distributions are
uncalibrated suggestions. Queue success and graph relationships do not establish
domain accuracy.
