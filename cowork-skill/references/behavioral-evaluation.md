# Behavioral checks

Check realistic scenarios: project resumption after context loss; stale notes
contradicted by current source; a recurring failure with a solved pattern; same
paths in different roots; hash conflicts; timed-out saves; read-only tasks; and a
release whose build passed but user acceptance remains open.

For cross-project transfer, give the agent only a task in Sample Beta and access to
the shared Brain containing Alpha's reusable lesson. Check that it retrieves by
problem pattern without being told the lesson path, reads the full source, compares
applicability and verifies the approach in Beta before claiming success. Keep this
behavioral evaluation separate from the HTTP demo and model-free retrieval tests;
neither demonstrates that an autonomous agent followed the workflow.

Expected behavior is evidence-led recall, correct scope, no invented authorization,
source verification and honest persistence status. Text matching alone is not
behavioral proof. Keep writes in temporary vaults. Distinguish simulations from real
task runs and retrieval scores from answer quality.
