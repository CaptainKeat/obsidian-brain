# Recall examples

Start narrow: project name plus failing command, exact error, path, model or port.
For example, search `Sample App persistence restart` in `roots=vault` with the
project folder included. Read the full applicable checkpoint before exploring code.

If identity fails, broaden to the underlying problem, such as `atomic save watcher
delete recreate`, in pattern/example folders. Compare applicability before reusing
a fix. Search another root when the source lives in project docs rather than notes.

Use `mode=all` for historical rationale or a missing successor. Rank is not
confidence, mtime is not verification, and graph edges are not current truth.
Stop recall once sufficient evidence supports the next action.
