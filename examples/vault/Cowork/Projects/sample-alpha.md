# Sample Alpha

This is a fictional desktop notes application, provided only as a demonstration.
Its example checkpoint records a worker crash-recovery approach: a supervisor
checks the owned loopback worker and respects persistent pause. The reusable
procedure lives in [[Cowork/Patterns/owned-worker-recovery]].

No real application acceptance or production result is claimed by this fixture.
